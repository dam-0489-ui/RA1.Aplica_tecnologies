# 06 - Android Studio

## Què és Android Studio?

Android Studio és l'entorn de desenvolupament principal per a aplicacions Android.

Inclou eines per:

- editar codi;
- gestionar projectes;
- configurar l'Android SDK;
- crear emuladors;
- depurar aplicacions;
- executar aplicacions;
- analitzar el rendiment.

## Components habituals

```text
Android Studio
    |
    +-- Android SDK
    +-- SDK Manager
    +-- Device Manager
    +-- Android Emulator
    +-- Gradle
    +-- Debugger
```

## Crear un projecte Android

El flux general és:

1. Crear un projecte.
2. Escollir la plantilla.
3. Configurar el nom.
4. Configurar el package/application ID.
5. Seleccionar la configuració del projecte.
6. Implementar l'aplicació.
7. Executar-la en un emulador o dispositiu físic.

## Flutter i Android Studio

Android Studio també pot utilitzar-se per desenvolupar Flutter instal·lant el plugin Flutter.

```text
Android Studio
+
Flutter SDK
+
Flutter plugin
+
Dart
```
