# 03 - iOS

## Característiques

iOS és el sistema operatiu mòbil d'Apple.

Els apunts originals destaquen:

- entorn controlat per Apple;
- integració amb altres dispositius Apple;
- APIs pròpies;
- integració amb serveis com Siri, iCloud, Apple Pay i Apple Maps;
- control de les aplicacions publicades a l'App Store;
- sandboxing i permisos;
- integració estreta entre sistema, software i hardware.

## Desenvolupament natiu

Actualment el llenguatge principal és:

```text
Swift
```

L'entorn de desenvolupament és:

```text
Xcode
```

I les tecnologies d'interfície principals inclouen:

```text
SwiftUI
UIKit
```

## Història resumida

- 2007: primer iPhone.
- 2008: App Store.
- 2010: primer iPad.
- Posteriorment Apple amplia l'ecosistema amb Apple Watch i altres dispositius.

## Important

Per desenvolupar aplicacions iOS natives cal treballar amb l'ecosistema de desenvolupament d'Apple. Flutter també permet crear aplicacions iOS, però continua sent necessari tenir en compte les eines i requisits específics d'Apple per construir i publicar aplicacions iOS.
