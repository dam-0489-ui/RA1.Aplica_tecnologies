# 01 - Introducció

## Dispositius mòbils

Els terminals mòbils actuals ofereixen capacitats similars a les d'un ordinador personal. Un dels principals avantatges de la tecnologia mòbil és la seva portabilitat.

Els principals sistemes operatius tractats en aquests apunts són:

- Android
- iOS

També s'introdueix el desenvolupament multiplataforma amb Flutter.

## Objectius

En aquest RA1 treballarem:

- característiques dels sistemes operatius mòbils;
- arquitectura d'Android;
- components d'una aplicació Android;
- `AndroidManifest.xml`;
- eines de desenvolupament;
- Android Studio;
- Kotlin i Swift;
- Flutter i Dart;
- configuració de l'entorn de desenvolupament.

## Desenvolupament natiu i multiplataforma

### Natiu

Cada plataforma utilitza les seves pròpies eines i APIs.

```text
Android -> Kotlin + Android SDK + Android Studio
iOS     -> Swift + iOS SDK + Xcode
```

### Multiplataforma

Flutter permet crear aplicacions per a diferents plataformes compartint una gran part del codi.

```text
Dart + Flutter
      |
      +-- Android
      +-- iOS
      +-- Web
      +-- Windows
      +-- Linux
      +-- macOS
```
