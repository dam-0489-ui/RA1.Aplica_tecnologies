## Elements comuns

En totes quatre opcions necessitarem:

- Flutter SDK
- Dart
- Android SDK
- Android Emulator o dispositiu físic
- Git
- eines de desenvolupament
- `flutter doctor`

## Comprovació final

```bash
flutter doctor
```

I, per veure els dispositius:

```bash
flutter devices
```
