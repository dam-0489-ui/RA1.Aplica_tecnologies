# 02 - Android

## Característiques

Android és un sistema operatiu mòbil basat en Linux i desenvolupat sobre l'ecosistema Android Open Source Project (AOSP).

Característiques principals:

- adaptable a diferents fabricants i dispositius;
- mòbils, tauletes, televisors, rellotges i altres dispositius;
- APIs per a geolocalització, càmera, sensors, xarxes i multimèdia;
- sistema de permisos;
- sandboxing i aïllament de les aplicacions;
- desenvolupament natiu amb Kotlin;
- possibilitat d'utilitzar frameworks multiplataforma com Flutter.

## Android modern

Els apunts originals descriuen versions antigues d'Android i indiquen Android 16 com a versió de 2025. En consultar versions actuals cal distingir sempre entre versions estables i versions de desenvolupament o beta.

## Història resumida

- 2005: Google compra Android Inc.
- 2007: Open Handset Alliance.
- 2008: primer dispositiu Android comercial, T-Mobile G1.
- 2011: Android 4.0 unifica l'experiència de mòbils i tauletes.
- 2015: Android 6.0 Marshmallow.
- 2016: Android 7.0 Nougat.
- 2017: Android 8.0 Oreo.
- 2018: Android 9 Pie.
- 2019: Android 10.
- 2020: Android 11.
- 2021: Android 12.
- 2022: Android 13.
- 2023: Android 14.
- 2024: Android 15.
- 2025: Android 16.
